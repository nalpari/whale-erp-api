# TO-DO 목록 담당직원 이름 검색 (api)

근거: WHALEERP-713, 2026-11-13 재영 결정(기획 세션 header 전달). 명세 「TO-DO 관리」 변경 제안 P-20261113-145852-9f78.

## 고칠 것

- `ListTodosQueryDto`에 `assigneeName`을 더한다.
  - 앞뒤 공백을 지우고, 비면 없는 것으로 본다. 50자까지 받는다. 직원 목록 `keyword`와 같은 규칙이다.
- `TodosService.list`: 배정 직원 가운데 이름이 부분 일치하는 사람이 한 명이라도 있는 행을 고른다(`todoAssignees some`).
  - 개인 배정은 그 직원, 근무지 전체(각자 수행 · 한 명 수행)는 대상 직원 가운데 한 명이다.
  - 부분 일치는 `containsText`(대소문자 무시, `%` · `_` · `\` 이스케이프)를 쓴다.
  - 본사 역할(BM · BA)에게 본사 제공 동의를 하지 않은 가맹 직원, 폐점한 가맹 점포 직원의 이름으로는 걸리지 않는다. 직원 레코드 조건 `hqVisibleWhere(...).staff`(근로계약 목록 · 홈과 같은 기준, 운영 정책 ATT-30)를 함께 건다.
  - 직원 필터(`staffMemberId`)와 같이 오면 둘 다 만족해야 한다(AND).
  - 배정 그룹은 지금처럼 필터에 맞는 행끼리 한 줄로 묶는다(직원 필터와 같음).
- 마이그레이션은 없다.

## 검증

- 단위 테스트: where 모양(이름 조건 · 이스케이프 · 동의 조건 · 직원 필터와 AND), DTO(공백 · 빈 값 · 51자).
- 로컬 실화면: front와 함께 이름 검색, 전체 배정 건, 본사 계정에서 동의하지 않은 가맹 직원 이름으로 0건.
