- 문서 번호 `WHALE-RPT`, 문서 이름 완료보고서, 작성자 인터플러그, 버전 1.0. `revisions.json` 에 넣는다.

- 전체 영역을 싣는다. 숫자는 손으로 적지 않고 다른 생성기의 원본과 셈 함수에서 읽는다. 값을 못 읽거나 합이 맞지 않으면 멈춘다.

## 절과 원본

| 절 | 내용 | 원본 |
|---|---|---|
| 1. 프로젝트 개요 | 목적 · 대상, 화면 구분, 영역별 사용 중 메뉴 · 화면 | `manyfast_prd.json`, `menus.json`, `screens/areas` |
| 2. 수행 범위 | 영역별 화면 수와 사용 메뉴 수, 제외 범위 | `screens/areas`, `menus.json`, 운영 정책 「1차 범위에서 제외」 |
| 3. 산출물 목록 | 문서 번호 · 산출물 · 형식 · 버전 · 기준 9종 | `revisions.json`, 생성 때 남긴 `out/manifest.json` |
| 4. 결과 요약 | 요구사항 · 기능 · 명세, 메뉴, 테이블 · 컬럼, API, 규칙, 화면, 흐름 | 각 생성기의 셈 함수 |
| 5. 테스트 결과 요약 | 저장소 · 종류별 합계, 실패 · 제외 건수와 사유 | `test_results.json` |
| 6. 잔여 사항 | 외부 검토, 2차로 미룬 항목, 테스트 실패 처리 계획 | 운영 정책 「아직 정해지지 않은 것」, `test_results.json` |

- 목적은 PRD goal 의 첫 문장, 대상은 targetUser 를 표준 용어로만 고친 글이다(`sources/manyfast_prd.json`, 2026-11-09 읽음). goal 의 둘째 문장과 background 는 팀 표시와 범위 메모가 있어 쓰지 않는다.
- 제공 기능은 요구사항 문장을 쓰지 않는다. 1차에 없는 기능이 나가지 않게 사용 중인 메뉴와 화면 이름으로 적는다.
- 사용 메뉴는 `ACTIVE` 이고 지우지 않은 메뉴다. 영역 표의 합이 메뉴 스냅숏의 사용 메뉴 수와 다르면 멈춘다.
- 실패 · 제외 건수는 실패한 테스트, 테스트 밖 실패, 린트 오류를 하나씩 센다. 표의 합이 원본 목록 수와 다르면 멈춘다.
- 린트 · 타입 오류의 사유는 규칙 이름까지만 적는다. 오류 문장 전체는 테스트 결과서에 있다.

## 멈추는 경우

- 메뉴 스냅숏의 마지막 마이그레이션이 저장소의 마지막 것과 다를 때.
- 납품본에서 산출물 8종의 기록 · 파일 · 해시 · 버전 · 기준이 맞지 않거나, 작업 트리가 깨끗하지 않거나, 깨끗하지 않은 트리에서 만든 문서가 있거나, 운영 정책 사본이 원본과 다를 때(원본을 볼 수 있을 때).
- `--draft` 는 위 확인을 건너뛰고 경고를 찍으며, 표지 · 머리글 · 제목 속성에 「초안」을, 파일 이름에 `_초안` 을 붙인다. 납품본 이름의 파일은 만들지 않는다.
- 테스트 요약의 실패 · 제외 칸과 목록이 어긋날 때(단위 · e2e 는 실패 + 테스트 밖 실패, 린트는 실패 파일 수, 타입은 유무).
- `revisions.json` 문서가 9종이 아닐 때, 각 생성기의 셈이 멈출 때(API 문서와 소스가 어긋남 등).
- 표지 · 개정 이력 · 머리글 · 본문 · 표의 글자에 쟁점 번호, 「쟁점」, 팀 표시, 팀원 실명, 일감 · PR 번호, 내부 도구 이름, 미결 메모, 실제 이메일 · 휴대전화번호, 저장소 경로, 자리표시자, 옛 근로계약 상태 이름이 남을 때. 바닥글과 문서 속성까지 본다. 납품본에서는 「미분석」 · 「미확인」도 멈춘다. 실패 사유 원문은 싣지 않는다.

## 넣지 않는 것

일정, 투입 인력, 비용, 성과 평가, 고객 확인 · 검수 결과, 수동 테스트 결과. 근거 문서가 없다.

## 실행

```bash
.venv/bin/python build_completion_report.py --version 1.0
.venv/bin/python test_build_completion_report.py
```

전체 재생성 때는 다른 원본을 모두 갱신해 커밋한 뒤, 깨끗한 작업 트리에서 8종을 만들고 맨 마지막에 돌린다. 각 생성기는 `out/manifest.json` 에 문서 파일 · 해시 · 기준 · 작업 트리 상태를 남긴다.
