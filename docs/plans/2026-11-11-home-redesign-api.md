# 로그인 후 홈 개편 — api (WHALEERP-665)

근거: 2026-11-11 재영 결정, 운영 정책 v277 HOM-03~10, 용어집(확인 필요(홈) · 점포별 확인 필요). front 는 따로 PR 로 올린다.

## 바꾸는 것

### `GET /home/summary`

- **운영 점포만 센다.** 업무 범위에서 폐점은 지금처럼 빼고, 미운영(`NOT_OPERATING`)도 카드 · 표 집계에서 뺀다(HOM-06 · HOM-10). 운영 점포 카드에 `notOperating`(미운영 수)을 더한다. 열을 더하면 카드와 같도록 재직 직원 · 오늘 출근 · 오늘 TO-DO 카드도 운영 점포만 센다.
- **점포별 현황 표**: 일곱 곳 제한을 없애고 운영 점포 모두를 준다. 정렬은 그대로(확인 필요 많은 순 → 점포명).
- **점포별 열 추가**
  - `notCheckedInCount` — 점포별 미출근. 카드의 미출근과 같은 판정(attendanceDayStatus ABSENT)과 가림.
  - `todayTodo` — 점포별 오늘 TO-DO `{ done, total }`. 수행 날짜가 오늘(한국 날짜)인 TO-DO 를 묶음(배정 그룹) 하나로 세고, 묶음의 행이 모두 완료여야 완료다. TO-DO 조회 권한이 없으면 null.
- **점포별 확인 필요(`pendingActionCount`)에 계약 갱신 예정을 더한다**(HOM-03). 서명 요청 전은 넣지 않는다(지금 그대로).
- **카드 `todayTodo`** — `{ done, total }`. 점포별 값의 합이다.

### `GET /home/pending`

- **계약 갱신 예정** 줄의 대상을 종료 30일 안(갱신 예정 알림 기준 `RENEWAL_NOTICE_DAYS`)으로 넓힌다. 지금은 경고 밴드 기준인 7일이다. 점포별 확인 필요 열도 같은 30일이다.
- 갱신 예정 줄에 `dueInDays`(가장 먼저 끝나는 계약의 종료까지 남은 날, 한국 날짜)를 더한다. 화면이 D-N 으로 적고 7일 이내면 빨간색이다(HOM-04).
- **경고 밴드용 `renewals` 배열을 없앤다**(HOM-04, 밴드 없앰). `HomeRenewalDto` 도 지운다.
- 확인 필요 영역은 지금처럼 미운영 점포 건까지 센다(HOM-07).

## 그대로 두는 것

- 영역 권한(그 메뉴 조회 권한이 없으면 null), 본사 역할의 계약 · 직원 가림(ATT-30), 플랫폼 계정 빈 결과.
- 퇴직으로 배정이 풀린 긴급 TO-DO 는 지금처럼 점포로 센다(HOM-03).
- 필드 이름(`pendingActionCount` 등). 화면 이름만 「확인 필요」로 바뀐다.

- 본사 역할이 가맹 점포를 볼 때도 오늘 TO-DO · 긴급 TO-DO 는 TO-DO 목록처럼 동의하지 않은 가맹 직원의 것을 빼지 않고 줄로 센다(2026-11-11 재영, 운영 정책 v278 HOM-10 · ATT-30). 눌러 간 목록과 숫자가 맞는다.
